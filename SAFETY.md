# Safety

This project only reads logged data. It never writes to, flashes, or tunes any vehicle module, and it does not support removing or disabling emissions equipment. It is not tuning advice and not a substitute for a qualified diesel mechanic. Use at your own risk. Logging while driving must be done by a passenger or left unattended.

## What this tool does not do
- It does not connect to the vehicle. It only reads CSV files you export.
- It does not write to, flash, or tune any module.
- It does not support emissions-delete or disabling emissions equipment (see the EPA Clean Air Act tampering policy).
- It does not give tuning advice. AI notes only explain flagged data.
- It is not a substitute for a qualified mechanic.

## Logging safely
1. Engine off, key on: read DTCs only. Do not run module tests or service functions in FORScan.
2. Idle logs: parked, outdoors, brake set.
3. Drive logs: set up before moving. A passenger watches the laptop, or it stays closed. Never touch the laptop while driving. Keep cables away from the pedals.
4. Unplug the adapter afterward if it has no sleep mode.
